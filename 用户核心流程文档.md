# forum-java 用户核心流程文档

## 1. 用户注册流程

### 流程描述
用户通过邮箱和密码完成账号注册,系统自动完成登录并颁发访问凭证。

### 技术实现路径
```
前端表单 → UserRestController → UserApiService → UserManager → UserRepository → 数据库
```

### 详细步骤

```mermaid
sequenceDiagram
    participant User as 用户
    participant Frontend as 前端页面
    participant Controller as UserRestController
    participant Service as UserApiService
    participant Manager as UserManager
    participant Repo as UserRepository
    participant DB as MySQL数据库
    participant Cache as 缓存服务

    User->>Frontend: 填写邮箱/密码/昵称
    Frontend->>Controller: POST /user-rest/register
    Controller->>Service: register(request)
    Service->>Manager: register(request)
    
    Manager->>Repo: getByEmail(email)
    Repo->>DB: SELECT * WHERE email=?
    DB-->>Repo: 查询结果
    Repo-->>Manager: 返回User对象
    
    alt 邮箱已存在
        Manager-->>Service: 抛出异常:邮箱已注册
        Service-->>Controller: 返回错误
        Controller-->>Frontend: 注册失败
    else 邮箱未注册
        Manager->>Manager: MD5加密密码
        Manager->>Repo: save(newUser)
        Repo->>DB: INSERT INTO user
        DB-->>Repo: 插入成功
        
        Manager->>Manager: 触发事件:USER_REGISTER
        Manager->>Manager: login(user, request)
        Manager->>Cache: 存储登录token
        Cache-->>Manager: 返回token
        Manager-->>Service: 返回token
        Service-->>Controller: 返回token
        Controller->>Controller: 写入Cookie(sid=token)
        Controller-->>Frontend: 注册成功
        Frontend-->>User: 跳转到首页
    end
```

### 关键代码位置
- **Controller**: `forum-portal/src/main/java/pub/developers/forum/portal/controller/rest/UserRestController.java:42`
- **Manager**: `forum-app/src/main/java/pub/developers/forum/app/manager/UserManager.java:148`
- **核心校验**: 邮箱唯一性检查、密码MD5加密
- **事件触发**: `EventBus.emit(EventBus.Topic.USER_REGISTER, registerUser)`

## 2. 用户登录流程

### 流程描述
用户使用邮箱和密码登录,验证通过后系统颁发访问凭证并缓存用户信息。

### 技术实现路径
```
前端表单 → UserRestController → UserApiService → UserManager → UserRepository → 数据库/缓存
```

### 详细步骤

```mermaid
sequenceDiagram
    participant User as 用户
    participant Frontend as 前端页面
    participant Controller as UserRestController
    participant Service as UserApiService
    participant Manager as UserManager
    participant Repo as UserRepository
    participant DB as MySQL数据库
    participant Cache as 缓存服务

    User->>Frontend: 输入邮箱/密码
    Frontend->>Controller: POST /user-rest/login
    Controller->>Service: emailLogin(request)
    Service->>Manager: emailRequestLogin(request)
    
    Manager->>Repo: getByEmail(email)
    Repo->>DB: SELECT * WHERE email=?
    DB-->>Repo: 返回用户数据
    Repo-->>Manager: 返回User对象
    
    alt 用户不存在
        Manager-->>Service: 抛出异常:用户不存在
    else 用户已禁用
        Manager-->>Service: 抛出异常:账号已禁用
    else 密码错误
        Manager->>Manager: MD5加密输入密码
        Manager->>Manager: 对比数据库密码
        Manager-->>Service: 抛出异常:密码错误
    else 验证通过
        Manager->>Repo: update(lastLoginTime)
        Repo->>DB: UPDATE user SET last_login_time=?
        Manager->>Manager: login(user, request)
        Manager->>Cache: 生成token并缓存用户信息
        Cache-->>Manager: 返回token
        Manager-->>Service: 返回token
        Service-->>Controller: 返回token
        Controller->>Controller: 写入Cookie(sid=token)
        Controller-->>Frontend: 登录成功
        Frontend-->>User: 跳转到首页
    end
```

### 关键代码位置
- **Controller**: `forum-portal/src/main/java/pub/developers/forum/portal/controller/rest/UserRestController.java:53`
- **Manager**: `forum-app/src/main/java/pub/developers/forum/app/manager/UserManager.java:53`
- **核心校验**: 用户存在性、账号状态、密码MD5校验
- **缓存策略**: token → User对象映射,userId → token映射

## 3. 文章/问答发布流程

### 流程描述
登录用户填写标题、内容、选择分类和标签后提交,系统进行审核状态管理并触发相关事件。

### 技术实现路径
```
前端编辑器 → ArticleRestController → ArticleApiService → ArticleManager → ArticleRepository → 数据库
```

### 详细步骤

```mermaid
sequenceDiagram
    participant User as 登录用户
    participant Frontend as 前端编辑器
    participant Controller as ArticleRestController
    participant Service as ArticleApiService
    participant Manager as ArticleManager
    participant TagRepo as TagRepository
    participant TypeRepo as ArticleTypeRepository
    participant Repo as ArticleRepository
    participant DB as MySQL数据库

    User->>Frontend: 填写标题/内容/选择分类/标签
    Frontend->>Controller: POST /article-rest/save
    Controller->>Controller: 从Cookie获取token
    Controller->>Service: saveArticle(request)
    Service->>Manager: saveArticle(request)
    
    alt 新建文章(id为空)
        Manager->>TypeRepo: 校验文章分类是否存在且已审核
        TypeRepo->>DB: SELECT * FROM article_type
        DB-->>TypeRepo: 返回分类数据
        TypeRepo-->>Manager: 返回ArticleType
        
        Manager->>TagRepo: 校验标签是否全部存在
        TagRepo->>DB: SELECT * FROM tag WHERE id IN (?)
        DB-->>TagRepo: 返回标签列表
        TagRepo-->>Manager: 返回Tag集合
        
        Manager->>Manager: 构建Article实体(auditState=WAIT)
        Manager->>Repo: save(article)
        Repo->>DB: INSERT INTO posts
        DB-->>Repo: 插入成功,返回ID
        
        Manager->>Manager: 触发事件:ARTICLE_CREATE
        Manager-->>Service: 返回文章ID
    else 更新文章(id不为空)
        Manager->>Repo: 查询文章是否存在
        Manager->>Manager: 校验当前用户是否为作者
        Manager->>TypeRepo: 校验新分类
        Manager->>TagRepo: 校验新标签
        Manager->>TagRepo: 删除旧标签关联关系
        Manager->>Repo: update(article)
        Repo->>DB: UPDATE posts SET ...
        Manager->>Manager: 触发事件:ARTICLE_UPDATE
        Manager-->>Service: 返回文章ID
    end
    
    Service-->>Controller: 返回结果
    Controller-->>Frontend: 返回文章ID
    Frontend-->>User: 跳转到文章详情页
```

### 关键代码位置
- **Controller**: `forum-portal/src/main/java/pub/developers/forum/portal/controller/rest/ArticleRestController.java:30`
- **Manager**: `forum-app/src/main/java/pub/developers/forum/app/manager/ArticleManager.java:53`
- **核心校验**: 
  - 分类校验: `forum-app/src/main/java/pub/developers/forum/app/manager/ArticleManager.java:271`
  - 标签校验: 继承自AbstractPostsManager
  - 作者权限校验(更新时): `ArticleManager.java:75`
- **审核机制**: 新建文章默认`auditState=WAIT`,需管理员审核后才能公开展示
- **事件触发**: `ARTICLE_CREATE`、`ARTICLE_UPDATE`

## 4. 评论发布流程

### 流程描述
登录用户在文章/问答详情页填写评论内容并提交,系统自动关联到对应帖子。

### 技术实现路径
```
前端评论框 → CommentRestController → CommentApiService → CommentManager → CommentRepository → 数据库
```

### 详细步骤

```mermaid
sequenceDiagram
    participant User as 登录用户
    participant Frontend as 文章详情页
    participant Controller as CommentRestController
    participant Service as CommentApiService
    participant Manager as CommentManager
    participant PostsRepo as PostsRepository
    participant Repo as CommentRepository
    participant DB as MySQL数据库

    User->>Frontend: 填写评论内容
    Frontend->>Controller: POST /comment-rest/create
    Controller->>Controller: 从Cookie获取token
    Controller->>Service: create(request)
    Service->>Manager: create(request)
    
    Manager->>Manager: 从登录上下文获取用户信息
    Manager->>PostsRepo: 校验帖子是否存在
    PostsRepo->>DB: SELECT * FROM posts WHERE id=?
    DB-->>PostsRepo: 返回帖子数据
    PostsRepo-->>Manager: 返回Posts对象
    
    alt 帖子不存在
        Manager-->>Service: 抛出异常:帖子不存在
    else 帖子存在
        Manager->>Manager: 构建Comment实体
        Manager->>Repo: save(comment)
        Repo->>DB: INSERT INTO comment
        DB-->>Repo: 插入成功
        
        Manager->>Manager: 触发事件:COMMENT_CREATE
        Manager-->>Service: 返回成功
        Service-->>Controller: 返回成功
        Controller-->>Frontend: 刷新评论列表
        Frontend-->>User: 显示新评论
    end
```

### 关键代码位置
- **Controller**: `forum-portal/src/main/java/pub/developers/forum/portal/controller/rest/CommentRestController.java:29`
- **核心逻辑**: 继承自AbstractPostsManager的评论管理能力
- **事件触发**: `EventBus.Topic.COMMENT_CREATE`

## 5. 点赞功能流程

### 流程描述
登录用户对文章/问答点赞或取消点赞,系统记录点赞关系并更新统计数据。

### 技术实现路径
```
前端点赞按钮 → ApprovalRestController → ApprovalApiService → ApprovalManager → ApprovalRepository → 数据库
```

### 详细步骤

```mermaid
sequenceDiagram
    participant User as 登录用户
    participant Frontend as 文章详情页
    participant Controller as ApprovalRestController
    participant Service as ApprovalApiService
    participant Manager as ApprovalManager
    participant Repo as ApprovalRepository
    participant DB as MySQL数据库

    User->>Frontend: 点击点赞按钮
    
    alt 点赞操作
        Frontend->>Controller: POST /approval-rest/create/{postsId}
        Controller->>Controller: 从Cookie获取token
        Controller->>Service: create(postsId)
        Service->>Manager: create(postsId)
        
        Manager->>Manager: 从登录上下文获取用户ID
        Manager->>Repo: 检查是否已点赞
        Repo->>DB: SELECT * WHERE posts_id=? AND user_id=?
        DB-->>Repo: 返回查询结果
        
        alt 已点赞
            Manager-->>Service: 返回已点赞提示
        else 未点赞
            Manager->>Repo: save(approval)
            Repo->>DB: INSERT INTO approval
            DB-->>Repo: 插入成功
            Manager->>Manager: 触发事件:APPROVAL_CREATE
            Manager-->>Service: 返回点赞数
        end
        
    else 取消点赞
        Frontend->>Controller: POST /approval-rest/delete/{postsId}
        Controller->>Service: delete(postsId)
        Service->>Manager: delete(postsId)
        
        Manager->>Repo: 查询点赞记录
        Repo->>DB: SELECT * WHERE posts_id=? AND user_id=?
        DB-->>Repo: 返回点赞记录
        
        alt 存在点赞记录
            Manager->>Repo: delete(approvalId)
            Repo->>DB: DELETE FROM approval WHERE id=?
            Manager->>Manager: 触发事件:APPROVAL_DELETE
        else 无点赞记录
            Manager-->>Service: 直接返回成功
        end
    end
    
    Service-->>Controller: 返回结果
    Controller-->>Frontend: 返回新的点赞数
    Frontend-->>User: 更新点赞按钮状态和数量
```

### 关键代码位置
- **Controller**: `forum-portal/src/main/java/pub/developers/forum/portal/controller/rest/ApprovalRestController.java:25`
- **API定义**: `forum-api/src/main/java/pub/developers/forum/api/service/ApprovalApiService.java:12`
- **核心功能**:
  - 创建点赞: `create(postsId)`
  - 取消点赞: `delete(postsId)`
  - 检查点赞状态: `hasApproval(postsId)` (在文章详情页使用)

## 架构说明

### 分层架构
```
forum-portal (Controller层) 
    ↓
forum-facade (API实现层/参数校验)
    ↓
forum-app (Manager业务逻辑层)
    ↓
forum-domain (领域实体层)
    ↓
forum-infrastructure (Repository数据访问层)
    ↓
MySQL数据库
```

### 核心技术组件
- **Web框架**: Spring Boot 2.3.3 + Spring MVC
- **持久层**: MyBatis + PageHelper
- **缓存**: CacheService (支持Redis/本地缓存)
- **连接池**: HikariCP
- **JSON处理**: Fastjson 1.2.69
- **模板引擎**: Thymeleaf
- **前端**: Bootstrap + Mavon-Editor

### 认证机制
- **凭证存储**: Cookie中的`sid`字段存储token
- **权限校验**: `@IsLogin`注解 + AOP切面
- **用户上下文**: `LoginUserContext` ThreadLocal存储
- **登录状态**: token → User对象缓存映射

### 事件驱动
系统使用`EventBus`实现异步事件处理:
- `USER_REGISTER`: 用户注册(操作日志、通知管理员)
- `USER_LOGIN`: 用户登录(操作日志)
- `USER_LOGOUT`: 用户登出(操作日志)
- `ARTICLE_CREATE`: 文章创建(统计、通知)
- `ARTICLE_UPDATE`: 文章更新(历史记录)
- `COMMENT_CREATE`: 评论创建(消息通知、统计)
- `APPROVAL_CREATE`: 点赞创建(消息通知)

### 审核机制
内容发布采用审核制:
- **审核状态**: `WAIT`(待审核)、`PASS`(通过)、`REJECT`(拒绝)
- **可见性**: 仅作者本人和管理员可见待审核内容
- **管理员权限**: 可设置置顶、官方、精华等标记
